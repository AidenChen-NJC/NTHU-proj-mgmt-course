為什麼 800 萬銅原料完全融不到錢？

  • 銀行手冊只接受不動產、上市股票、現金存款做擔保品
  • 商品價格波動大 — 銅、鋼、油都被歸類「不可控風險」
  • 沒有計量工具來算「最壞會跌多少」 — 只能保守拒絕
  • 變現性疑慮 — 信評部不知道急售要折價多少
  • 結果:陳老闆 800 萬庫存 = 0 萬可融資 → 整個案件直接退件

714 萬
5 天 95% VaR · LTV 89.3% · 銅原料 800 萬

用 Value-at-Risk 計算「實際風險暴露」

  • 取銅 252 個交易日歷史 → 跑歷史模擬 + 參數法雙重 VaR
  • 5 天 95% 信賴區間 → 最大可能跌幅 5.69%
  • 扣 5% 安全邊際後 → 推薦 LTV 89.3%
  • 800 萬庫存 × 89.3% = NT$ 714 萬可抵押
  • 監理可解釋:VaR 是 Basel II 標準量化方法，非黑箱
